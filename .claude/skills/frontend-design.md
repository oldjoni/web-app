# Frontend Design Skill Overview

This skill enables creation of distinctive, production-grade web interfaces that prioritize authentic design over generic AI aesthetics.

## Core Purpose
The skill guides developers in building "components, pages, artifacts, posters, or applications" with exceptional visual quality and functional code.

## Design Philosophy

**Strategic Approach**: Before coding, establish a clear aesthetic direction by considering purpose, tone, constraints, and differentiation. The guidance emphasizes that "bold maximalism and refined minimalism both work - the key is intentionality, not intensity."

**Key Aesthetic Priorities**:
- **Typography**: Use distinctive, characterful fonts rather than defaults; pair display and body fonts intentionally
- **Color & Theme**: Commit to cohesive palettes using CSS variables; favor dominant colors with sharp accents
- **Motion**: Prioritize high-impact moments like staggered page load reveals and scroll-triggered animations
- **Composition**: Embrace asymmetry, overlap, and unexpected layouts rather than predictable grids
- **Details**: Add atmospheric elements like textures, gradients, and decorative forms matching the overall aesthetic

## Critical Avoidances

The skill explicitly warns against "generic AI-generated aesthetics" including overused fonts, clichéd color schemes, predictable layouts, and cookie-cutter patterns.

## Implementation Standard

Match complexity to vision: maximalist designs require elaborate code; minimalist designs demand restraint and precision in spacing and typography.
