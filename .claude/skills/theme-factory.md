# Theme Factory

Styling toolkit to apply professional, cohesive design systems to presentations, documents, and web content.

## Key Capabilities

10 pre-configured themes, each with a cohesive color palette (hex codes) and complementary font pairings for headers and body text. Options range from Ocean Depths to Midnight Galaxy, each tailored for different contexts and audiences.

## How It Works

1. Display the theme showcase to visualize all available options
2. Request explicit user confirmation of their preferred theme
3. Apply the selected theme's colors and fonts consistently throughout the artifact

## Custom Theme Creation

For scenarios where existing themes don't fit, generate custom themes from user descriptions — create, review, then apply following the standard application workflow.

Complete specifications for each theme (color values and font selections) are maintained in the themes directory for consistent implementation.
