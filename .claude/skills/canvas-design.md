# Canvas Design Skill

A sophisticated two-step process for creating visual art.

## Step 1: Design Philosophy Creation

Produce a .md file articulating an aesthetic movement through 4-6 paragraphs emphasizing how ideas manifest via "form, space, color, composition" rather than text. The philosophy must "repeatedly emphasize" that final work appears "meticulously crafted" and represents "master-level execution."

## Step 2: Canvas Creation

Translate philosophy into visual artifacts (.pdf or .png) that are "90% visual design, 10% essential text." Work should appear "as if it took countless hours" and be worthy of museum display — achieved through refinement of existing elements rather than adding new graphics.

## Key Principles

- Text integration as visual accent, not explanation
- Sophisticated abstract composition over literal representation
- Embedded conceptual references that reward deep viewing
- Flawless technical execution with proper spacing and no overlaps
- Minimalist restraint prioritizing spatial communication

The skill treats design as disciplined art-making, borrowing language from "scientific observation" and "systematic" visual language to elevate conceptual work to gallery-quality standards.
