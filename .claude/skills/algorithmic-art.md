# Algorithmic Art Creation Framework

This document outlines a comprehensive system for generating computational art using p5.js with seeded randomness and interactive exploration.

## Core Process

The workflow follows three essential stages:

1. **Algorithmic Philosophy Creation** - Develop a computational aesthetic manifesto (4-6 paragraphs) emphasizing emergent behavior, mathematical relationships, and process-driven beauty rather than static imagery.

2. **Conceptual Deducing** - Identify subtle thematic threads to weave invisibly into parameters and behaviors, so the reference enriches depth without announcing itself.

3. **p5.js Implementation** - Express the philosophy through code, starting from `templates/viewer.html` as the foundation, keeping fixed UI structure while replacing only the algorithm and parameter controls.

## Philosophy Requirements

The algorithmic philosophy must emphasize craftsmanship repeatedly throughout. It should address:

- Computational processes and mathematical relationships
- Noise functions and randomness patterns
- Particle behaviors and field dynamics
- Temporal evolution and system states
- Parametric variation and emergent complexity

Key phrases like "meticulously crafted algorithm" and "master-level implementation" establish that the final work represents deep expertise refined through countless iterations.

## Implementation Standards

**Fixed Elements** (always maintain from template):
- Layout structure (header, sidebar, canvas area)
- Anthropic branding (Poppins/Lora fonts, light colors, gradients)
- Seed navigation (Previous/Next/Random/Jump buttons)
- Action buttons (Regenerate, Reset, Download)

**Variable Elements** (customize per artwork):
- Complete p5.js algorithm
- Parameter definitions and ranges
- Parameter UI controls (sliders, inputs, color pickers)
- Colors section (include only if needed)

## Technical Requirements

All artifacts must be:
- Self-contained single HTML files (no external dependencies except p5.js CDN)
- Fully functional in browsers immediately
- Built with seeded randomness for reproducibility
- Designed with parameters that emerge naturally from the philosophy rather than predetermined pattern types

The algorithm should flow directly from the philosophical vision, not from a menu of available techniques.
